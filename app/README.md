# 밥타임 — 서울아산병원 직원식당의 메뉴와 예상 대기를 보여 주는 시연용 웹앱(모의 데이터)
- 설치: `npm install`
- 개발 서버: `npm run dev`
- 테스트: `npm test`(단위), `npm run e2e`(Playwright, 390px·1280px)
- 시연: `/?at=2026-10-14T12:20`처럼 `at`으로 시각을 고정해요. 열 때마다 그 시각에서 시작해요. 시연 시간 시트의 "검수 직원 화면 열기"나 다른 탭의 `/staff`에서 줄 상태를 바꾸면 화면이 함께 바뀌어요. 직원 입력은 실제 시각으로 15분 동안 유지돼요

## 시연 순서
- 기준 시각: `/?at=2026-10-14T12:20`(수요일 점심)으로 열면 홈 결론이 "지금은 신관이 바로 드실 수 있어요"이고, 동관은 13시 15분, 서관은 12시 45분부터 한산해질 것으로 나와요. 머리글의 시연 시간 시트에서 요일과 시각을 바꿀 수 있어요
- 근무 건물: 홈 시트 맨 위의 "근무 건물: 미설정"을 눌러 건물을 고르면 도보 시간과 도착했을 때 대기를 더해 가장 빠른 식당을 알려 줘요. 예를 들어 서관을 고르면 "지금 출발하면 신관이 가장 빨라요, 걸어서 4분"이 나와요. 시트의 "설정 지우기"로 미설정으로 돌아가요(값은 `babttae.workBuilding`에 저장돼요)
- 식당 상세: 홈의 식당 줄을 누르면 오늘 예상 대기 막대, 평소 중식 혼잡 패턴(요일 × 10분), 위치와 "지도에서 보기"(`/map?venue=east` 등)가 있는 시트가 열려요
- 검수 직원 화면: `/staff?at=2026-10-14T12:20`(또는 시연 시간 시트의 "검수 직원 화면 열기")을 다른 탭에 열고 줄 상태나 품절을 입력하면 홈·메뉴가 함께 바뀌어요. 입력은 실제 시각으로 15분 동안 유지돼요
- 운영자 화면: `/ops?at=2026-10-14T12:20`(또는 "운영자 화면 열기")에서 지금 상황, 시간대별 입장 추정, 품절 기록, 만족도와 잔반, 내일 준비 제안을 볼 수 있어요. 모든 수치는 모의 데이터예요
- 알림: 알림 탭에서 받을 알림을 고르면 시연 시각 기준으로 토스트(권한을 허락하면 시스템 알림)가 떠요. 서관·신관이 같은 시각에 끝나면 마감 30분 전 알림은 하나로 합쳐 보내요

## 배포
- 색 토큰은 저장소 루트의 `design/tokens.css`에 있고 `src/index.css`가 `../../design/tokens.css`로 불러와요. 그래서 `app/`만 따로 올리면 빌드가 깨져요
- Vercel에는 저장소 전체를 연결하고 프로젝트 설정의 Root Directory를 `app`으로 지정해요. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`예요. 주소 새로 고침은 `vercel.json`의 rewrite가 `index.html`로 보내요
- shadcn ui 파일 중 `toggle`, `switch`, `slider`, `field`는 초점·트랙 대비를 위해, `toast`는 모바일 탭 막대 위에 띄우려고, `sheet`는 닫기 버튼을 44px로 키우려고 직접 고쳤어요. `npx shadcn add`로 다시 설치하면 이 수정을 다시 적용해야 해요

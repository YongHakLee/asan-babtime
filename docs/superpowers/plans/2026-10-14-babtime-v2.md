# 밥타임 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 서비스 이름을 「밥타임」으로 바꾸고, 직원식당을 동관·서관·신관 3곳으로 나누고, 다크 모드를 그래파이트 톤으로 다듬고, 이동+대기 추천·운영자 대시보드·평소 혼잡 패턴·원산지를 웹앱에 더하며, 제안서를 같은 구조와 시범 운영·성과 지표로 상세화한다.

**Architecture:** 기존 구조(순수 TS 도메인 `app/src/lib/*` + 정적 데이터 `app/src/data/*` + React 화면)를 유지한다. 식당 식별자를 3곳으로 나누되 메뉴 데이터는 메뉴 묶음(`east`/`westNew`)으로 공유한다. 새 계산(도보 추천, 패턴, 운영 요약)은 각각 독립 lib 모듈로 두고 화면은 그것을 구독만 한다. 제안서는 같은 md→pdf 파이프라인으로 갱신한다.

**Tech Stack:** 기존과 동일 — Vite, React 19, TS, shadcn/ui(Base UI, base-maia, hugeicons), Tailwind v4, Vitest, Playwright 1.64; 제안서는 markdown-it + Playwright PDF.

**Spec:** `docs/superpowers/specs/2026-10-14-babtime-v2-design.md` (선행: `docs/superpowers/specs/2026-10-14-asan-cafeteria-design.md`)

- 상태 글자: 여유 / 보통 / 줄 있음 / 혼잡 (여유 < 2분, 보통 2~5분, 줄 있음 5~10분, 혼잡 ≥ 10분). 직원 입력 15분(실제 시계). 추천 = 예상 대기 3분 미만 가장 이른 시각.

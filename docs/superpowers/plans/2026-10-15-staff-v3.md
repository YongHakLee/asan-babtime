# 밥타임 v3 (검수 직원 입력 4단계, 예측 점검) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 검수 직원 입력을 4단계 기록으로 바꾸고, 직원 화면에 입력 후 비교와 취소를, 운영자 화면에 입력 누락 표시를, 새 `/ops/accuracy`에 기간 예측 점검 그래프를 넣는다.

**Architecture:** 식당별 최신 값(`overrides`)을 입력 기록 배열(`staffLog`) 하나로 바꾸고 모든 화면이 이것만 읽는다. 모델 예측 계산은 새 `lib/model.ts`로 떼어 `override.ts`와 `status.ts`가 순환 없이 함께 쓴다. 예측 점검은 `lib/accuracy.ts`(모의 입력 생성 + 집계, 순수 함수)와 화면(`pages/Accuracy.tsx`, `components/ops/AccuracyBars.tsx`)으로 나눈다.

**Tech Stack:** Vite, React 19, react-router, Tailwind v4, shadcn(Base UI), Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-staff-v3-design.md`

1. 화면 시각(시연)과 실제 시각이 다른 입력: `/staff`를 `?at=` 없이(실제 시각, 배식 밖) 열고 넣은 입력은 홈에 15분 반영되지만 예측 점검 집계에는 들어가지 않아야 한다 → Task 4 `real entry outside weekday lunch is excluded`.

5. 기록 없는 기간: 시연 시각이 2026-10-12 11:10 이전이거나 저장 주간 밖이면 그래프 대신 빈 상태 문구 → Task 5 `shows the empty state before any input`.

**Interfaces:**
- Produces (`lib/model.ts`):
  - `modelWait(hall: DiningHallId, meal: MealKey, at: Date): { waitMinutes: number; level: CongestionLevel }` — 지금 `effectiveWait`의 덧씌우기 전 부분(자정 넘긴 야식은 시작한 날 인기도). 배식 중이 아니면 `{ waitMinutes: 0, level: 'ok' }`.
- Produces (`lib/override.ts`, 기존 `Override`, `OverrideKind`, `setOverride`, `getActiveOverride`, `overrideRemainingMs` 제거):
  - `interface StaffEntry { id: string; hall: DiningHallId; level: CongestionLevel; at: number; realAt: number; model: { level: CongestionLevel; waitMinutes: number }; cancelledAt?: number }`
  - `addStaffEntry(hall: DiningHallId, level: CongestionLevel, at: Date): StaffEntry` — `model`은 `modelWait(hall, getActiveMeal(hall, at), at)`(활성 끼니가 없으면 `{ level: 'ok', waitMinutes: 0 }`).
  - `cancelStaffEntry(id: string): void`
  - `getActiveEntry(hall: DiningHallId): StaffEntry | null` — 그 식당의 **마지막** 항목만 본다. 취소됐거나 실제 경과가 [0, 15분) 밖이면 `null`.
  - `entryRemainingMs(e: StaffEntry): number`
  - `staffEntriesOn(ymd: string): StaffEntry[]` — `seoulYmd(new Date(e.at)) === ymd`, 취소 포함, 입력 순서.
  - `lastEntryOn(hall: DiningHallId, ymd: string): StaffEntry | null` — 그 날 취소되지 않은 마지막 항목.
  - `allStaffEntries(): StaffEntry[]` — 형식 검사를 통과한 전체(Task 4가 씀).
  - `OVERRIDE_TTL_MS`, `SoldOut`, `setSoldOut`, `soldOutOn`, `isSoldOut`, `subscribeOverrides`는 이름·동작 유지. `subscribeOverrides`가 지켜보는 키는 `babttae.staffLog`, `babttae.soldout`.
- Produces (`lib/status.ts`): `effectiveWait` 시그니처 그대로. 직원 입력이 있으면 `{ waitMinutes: 맞춘 값, level: 입력 등급, source: 'staff' }`.

- [ ] **Step 1: `override.test.ts`의 override 묶음을 새 API 테스트로 바꾼다 (실패하는 테스트)**

  지우는 테스트: `override expires after 15 real minutes…`, `an override stored without realAt…`, `legacy westNew values` 중 `babttae.overrides` 부분. 품절·구독 테스트는 두고 구독 테스트의 `'babttae.overrides'`를 `'babttae.staffLog'`로 바꾼다. 새 테스트(가짜 시계 `vi.useFakeTimers({ toFake: ['Date'] })`, `vi.setSystemTime(new Date('2026-10-20T01:00:00Z'))`):

```ts
it('entry expires after 15 real minutes, whatever the demo clock says', () => {
  const e = addStaffEntry('east', 'busy', t('2026-10-14T12:18'))
  expect(e.at).toBe(t('2026-10-14T12:18').getTime())
  expect(getActiveEntry('east')?.level).toBe('busy')
  vi.setSystemTime(new Date('2026-10-20T01:14:59Z'))
  expect(entryRemainingMs(getActiveEntry('east')!)).toBe(1000)
  vi.setSystemTime(new Date('2026-10-20T01:15:00Z'))
  expect(getActiveEntry('east')).toBeNull()
})
it('stores the model prediction at the moment of input', () => {
  // 2026-10-14 12:20 동관은 모델이 '혼잡'(약 16분)으로 본다 (v2 보정 목표)
  const e = addStaffEntry('east', 'queue', t('2026-10-14T12:20'))
  expect(e.model.level).toBe('busy')
  expect(e.model.waitMinutes).toBeGreaterThanOrEqual(10)
})
it('records ok/0 as the model outside service', () => {
  expect(addStaffEntry('west', 'busy', t('2026-10-14T15:30')).model).toEqual({ level: 'ok', waitMinutes: 0 })
})
it('cancelling the last entry returns to the model, not to the previous entry', () => {
  const first = addStaffEntry('east', 'queue', t('2026-10-14T12:10'))
  const second = addStaffEntry('east', 'busy', t('2026-10-14T12:12'))
  cancelStaffEntry(second.id)
  expect(getActiveEntry('east')).toBeNull()
  expect(lastEntryOn('east', '2026-10-14')?.id).toBe(first.id)
  expect(staffEntriesOn('2026-10-14')).toHaveLength(2)
})
it('drops entries older than 48 real hours when saving', () => {
  addStaffEntry('east', 'ok', t('2026-10-14T12:00'))
  vi.setSystemTime(new Date('2026-10-22T01:00:01Z'))
  addStaffEntry('west', 'ok', t('2026-10-14T12:00'))
  expect(allStaffEntries().map((e) => e.hall)).toEqual(['west'])
})
it('ignores malformed staffLog entries and the old overrides key', () => {
  const now = Date.now()
  localStorage.setItem('babttae.overrides', JSON.stringify({ east: { hall: 'east', kind: 'queue', at: now, realAt: now } }))
  expect(getActiveEntry('east')).toBeNull()
  localStorage.setItem('babttae.staffLog', JSON.stringify({ not: 'an array' }))
  expect(allStaffEntries()).toEqual([])
  localStorage.setItem('babttae.staffLog', JSON.stringify([
    { id: 'a', hall: 'westNew', level: 'busy', at: now, realAt: now, model: { level: 'ok', waitMinutes: 0 } },
    { id: 'b', hall: 'east', level: 'jammed', at: now, realAt: now, model: { level: 'ok', waitMinutes: 0 } },
    { id: 'c', hall: 'east', level: 'busy', at: now, realAt: now },
  ]))
  expect(allStaffEntries()).toEqual([])
})
```
